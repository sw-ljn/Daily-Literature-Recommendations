# IEEE Example

## Pseudo Paragraph

Recent reviews suggest that structured retrieval pipelines improve literature coverage while keeping screening decisions auditable [1], [2]. The same studies argue that transparent logging is especially important when iterative citation expansion is used because later rounds can drift from the original review scope if criteria are not restated clearly [1].
